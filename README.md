# BOHO — Hair & Beauty Atelier

A responsive salon website inspired by the editorial composition, beauty imagery, rose palette. Original implementation and BOHO identity; no source code or images copied from the reference.

## Run locally

No build step or dependencies. Serve this folder with any static server:

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. Deploy the folder to GitHub Pages, Netlify, Cloudflare Pages, or any static host.

## Included

- Original typographic BOHO identity and SVG favicon
- Responsive full-height hero, image drift, entrance sequence, full-screen navigation
- Accessible native treatment accordions, booking and privacy dialogs
- Local appointment-request form with validation and text download
- Reduced-motion support, keyboard navigation, focus handling
- Self-hosted photographs; no framework or runtime dependencies

## Before business launch

This is a completed visual website with an intentionally local booking preview. It does **not** send requests or confirm appointments. Connect a real booking provider or backend, replace placeholder contact/location/opening-hour information, and approve the illustrative treatment menu before using it commercially. No invented testimonials or business claims are included.
